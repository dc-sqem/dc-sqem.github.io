# DC-SQEM project page

Static project page for **DC-SQEM: Medial Mesh Extraction by Dual Contouring with Spherical Quadric Error Metric**.

Open `index.html` locally, or serve this directory as a static website. The page has no build step.

## Publish on GitHub Pages

Create an empty public repository, put the **contents** of this directory at its root, and push them with Git or GitHub Desktop. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**. The included `.nojekyll` file tells GitHub Pages to serve the static files directly.

The paper PDF is about 40 MiB. GitHub's browser upload is limited to 25 MiB per file, so upload this site with Git or GitHub Desktop.

## Content and links

- `assets/DC_SQEM_final.pdf`: final manuscript PDF.
- `assets/DC_SQEM_sup.pdf`: supplementary PDF.
- `assets/*.jpg`: website renditions of figures from the manuscript project; use the source PDFs in the manuscript project for print-quality figures.
- Code links to <https://github.com/Jiafeimaochuanqi/dc_sqem>.

The data package is not mirrored on this site. Add its public download link if it is later hosted online. Likewise, the page intentionally has no arXiv or journal DOI link until those URLs are confirmed. The provisional BibTeX entry should be updated after the journal record is published.

The page loads web fonts from Google Fonts when online and falls back to local sans-serif fonts offline. All other page assets are local.
